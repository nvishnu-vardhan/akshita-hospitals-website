# Akshita Hospitals — GitHub Pages package

This package uses `index.html` as a self-contained single-file website. It contains the site's page sections/routes and embeds the site's image/video data, so no `assets` folder is required for this version.

Pages are available through hash routes such as:
- /#/index
- /#/about
- /#/gastroenterology
- /#/gynaecology
- /#/doctors
- /#/facilities
- /#/gallery
- /#/insurance
- /#/contact
- /#/appointment
- /#/privacy-policy
- /#/dr-pavan-kumar-reddy
- /#/dr-srilakshmi

The `404.html` redirects legacy `.html` paths to their corresponding hash route.

GitHub Pages custom domain: akshitahospitals.com
